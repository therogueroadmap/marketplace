# Contributing

Each plugin lives in its own repository under [therogueroadmap](https://github.com/therogueroadmap).
Open issues and pull requests there; this repository only holds the catalog.

A plugin enters the catalog when:

1. It installs from scratch with `/plugin install <plugin>@therogueroadmap`.
2. It works without private paths, private skills or undocumented tools.
3. Its README declares its requirements and its version has a tag and a CHANGELOG entry.

Every repository runs the shared publishable-content scanner from
[therogueroadmap/.github](https://github.com/therogueroadmap/.github).
